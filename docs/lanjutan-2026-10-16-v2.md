# Lanjutan Pasla: integrasi API v2

Tanggal: 16 Oktober 2026. Cabang: `riset/fase-0`.

Melanjutkan `serah-terima-2026-10-16.md`, langkah pertama integrasi v2 sudah selesai di lokal.
Perubahan belum di-push atau di-deploy.

## Perubahan

- `src/api/app.ts` memasang `registerV2` sebelum penanganan rute yang tidak ditemukan.
- `src/platform.ts` memakai kontrak dependensi API yang sama, sehingga signer, sumber,
  model BYOK, konfigurasi kolam, dan tenggat sampai ke aplikasi HTTP.
- `src/api/server.ts` membaca `PASLA_SIGNING_KEY` dan menghubungkan adapter peraturan, PDF,
  fatwa, KHES, ayat, hadis, dan turats. Factory model v2 hanya memakai kunci per permintaan.
- Tanpa kunci penandatangan, server tetap berjalan dan ketiga rute v2 menjawab 503.
- `openapi.yaml` mencatat ketiga rute beserta kontrak potongan, tanda tangan, dan NDJSON.
- Potongan tidak lengkap ditolak sebelum model dipanggil, bersama potongan palsu atau diubah.
- Pembacaan body berhenti ketika melewati batas byte, termasuk permintaan tanpa Content-Length.
- Pembatalan pembaca NDJSON diteruskan ke model. Waktu antrean termasuk tenggat permintaan.
- Respons sumber atau AI yang melewati tenggat berakhir, tetapi slot konkurensinya tetap
  ditahan sampai pekerjaan selesai. Ini mencegah pekerjaan latar menumpuk melampaui kolam.
- Sintesis mengirim `allowRetries: false`; adapter Claude meneruskannya sebagai `maxRetries: 0`.
  Perilaku bawaan pemanggil v1 tetap sama. Gemini yang terpasang tidak memakai retryOptions,
  dan adapter kompatibel OpenAI hanya mengirim satu permintaan.

## Verifikasi

Uji integrasi memakai data sintetis dan kunci Ed25519 sementara, tanpa menulis fixture ke cache
sumber. Cakupannya: kunci publik, CORS, pembukaan sumber, BYOK wajib, tanda tangan bukti dan
hasil, penolakan pemalsuan, body besar, pembatalan, tenggat, dan pemisahan kolam sumber/AI.

Uji server lokal menjalankan `src/api/server.ts` dalam mode `pilot-vm`, dengan dan tanpa kunci
sementara. Mode luring memastikan adapter terhubung tanpa panggilan berbayar atau jaringan sumber.

Validasi akhir memakai `npm run verify`: lint, OpenAPI, seluruh uji, typecheck, build mesin,
dan build web bawaan repo mesin.

## Batas yang masih ada

- Belum ada evaluasi mutu jawaban v2 dengan sumber asli dan model berbayar.
- Tenggat dapat menutup respons sumber, tetapi adapter sumber lama belum menerima AbortSignal.
  Pekerjaannya dapat berlanjut sampai timeout internal; slotnya tetap ditahan selama itu.
- Rotasi kunci sudah tersedia di dependensi aplikasi melalui `extraPublicKeysPem`, tetapi
  konfigurasi kunci publik lama melalui lingkungan server belum disediakan.
- `PASLA_SIGNING_KEY` produksi tetap perlu dipasang pemilik sebelum v2 diaktifkan di VPS.

2. Rencana dan penyaringan laporan.
